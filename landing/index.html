Decisões técnicas

Treino montado por orçamento de tempo

Cada exercício ocupa um slot de trabalho mais descanso. O gerador divide o tempo total pelo slot e escolhe os exercícios em rodízio entre os grupos musculares, sem repetir o anterior em sequência.

const totalSlots = Math.max(1,
  Math.floor(totalSeconds / slotSeconds))

const uniqueCount = structure === 'circuit'
  ? totalSlots
  : Math.max(1, Math.floor(totalSlots / sets))

Trecho de src/lib/workout-generator.ts.

Local-first, sem backend

Histórico e preferências em localStorage com chave versionada. Cada item é validado na leitura e uma falha de escrita não derruba o app. Guarda até 200 sessões.

Offline e instalável

Service worker com vite-plugin-pwa e precache do Workbox. Depois da primeira carga, o treino roda sem rede.

Dados reproduzíveis, licença respeitada

Um script busca um commit fixo do dataset, filtra os exercícios de peso corporal e gera o JSON do app. Os GIFs, com direitos de terceiros, não entram no repositório e são baixados na primeira execução.

Como rodar localmente

Não há versão hospedada: o app roda na sua máquina. A primeira execução leva cerca de um minuto para baixar os GIFs.

Requer Node.js 20.19 ou superior (ou 22.12+), git e acesso à rede nessa primeira vez.

git clone https://github.com/Miguel-de-Castro/fitness-app.git
cd fitness-app
npm install
npm run dev

Para testar o service worker, use npm run build e depois npm run preview.
